# musicits.github.io

`https://musicits.github.io/` 루트를 서빙하는 저장소입니다.

- `index.html` — 도구 모음 랜딩 페이지
- `naver79034692a7a496d9ff4b2c3ba5994dfd.html` — 네이버 서치어드바이저 소유확인 파일 (지우지 마세요)
- `robots.txt` · `sitemap.xml` — 검색엔진용

robots.txt 는 호스트 루트에 있을 때만 크롤러가 읽습니다. 하위 경로에 둔 것은 무시되므로,
개별 도구의 사이트맵도 여기 robots.txt 에서 함께 알립니다.

네이버 소유확인은 두 가지 방법을 모두 적용해 뒀습니다. 확인 파일과 `index.html` 의
`naver-site-verification` 메타 태그입니다. 둘 다 지우지 마세요.

도구 자체는 각각 별도 저장소입니다.
