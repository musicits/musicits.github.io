베어처럼 쓰고, 옵시디언처럼 잇는 노트

쓰는 감각은 베어와 같게, 저장은 그냥 .md 파일로. 나스에 있어서 회사·집·폰 어디서나 같은 노트를 엽니다.

맥은 ⌘, 윈도우는 Ctrl 로 읽으면 됩니다.

시작하기

주소

notes.musicits.com
구글 메일 확인 → 노트 로그인

로그인 유지

구글 확인은 한 달, 노트 로그인은 90일 동안 다시 묻지 않습니다

앱처럼 띄우기

크롬·엣지 주소창의 앱 설치 · 사파리 파일 → Dock에 추가

아이폰

사파리 공유 → 홈 화면에 추가

쓰는 동안 저절로 저장되고, 다른 기기는 몇 초 안에 받아 갑니다. 인터넷이 끊겨도 계속 쓸 수 있고, 다시 닿으면 보냅니다.

요청할 거리 정리
베어 파일과 같은 모양으로 저장합니다. 하위 항목은 탭 대신 띄어쓰기로, 윗 항목의 글이 시작하는 칸에 맞춥니다(0) 아래 3칸, - 아래 2칸). 베어 백업 272개를 열어 보고 맞춘 규칙이라, 베어로 다시 가져가도 모양이 그대로입니다.

제목

이렇게 치면# 10/16 Brain Dump
이렇게 보입니다H110/16 Brain Dump
  • # ~ ###### 뒤에 빈칸을 치면 제목 1~6. # 은 숨고, 쓰는 줄 왼쪽 여백에 H1 같은 표시만 보입니다.
  • ⌘ 1 ~ ⌘ 6 로 바꾸고, 같은 키를 한 번 더 누르면 본문으로 돌아갑니다.
  • 제목 맨 앞에서 ⌫ 를 누르면 본문이 됩니다.
  • 노트 제목에는 / 도 쓸 수 있습니다(10/16 Brain Dump).

글자 모양

글자를 고르고 단축키를 누르거나, 기호로 감싸 칩니다. 커서가 떠나면 기호는 숨고 모양만 남습니다.

모양치는 법단축키
굵게**글**⌘ B
기울임*글*⌘ I
밑줄~글~ (베어와 같은 물결 하나)⌘ U
형광펜==글==⌘ ⇧ H
취소선~~글~~⌘ ⇧ X
코드`글`⌘ `
링크[보일 말](주소)⌘ K

노트 잇기 · 태그옵시디언처럼

  • [[노트 이름]] 으로 다른 노트를 잇습니다. [[ 만 쳐도 목록이 뜹니다. [[노트#제목]] · [[노트|보일 말]] 도 됩니다.
  • ![[노트]] 는 그 노트를 끼워 넣어 보여 줍니다.
  • 정보 → 백링크: 이 노트를 가리키는 노트와, 이름만 나오는 노트(누르면 링크 걸기).
  • 노트 이름을 바꾸면 다른 노트의 링크도 같이 고칩니다.
  • 태그는 #태그 · #상위/하위 · 빈칸이 있으면 #여러 단어#.
  • 쓰는 줄에서 링크를 열 때는 ⌘ 를 누른 채 누릅니다.

일기 · 달력

  • 달력 위 회사 | 블로그 를 고르고 날짜를 한 번 누르면 그날 일정, 한 번 더 누르면 그 종류의 일기가 열립니다. ⌥ D 는 오늘 일기.
  • 날짜 밑 점: 빨강 회사 · 파랑 블로그 · 회색 iCloud 일정.
  • iCloud 캘린더는 설정 → 연결에서 애플 앱 전용 암호로 붙입니다(애플 비밀번호 자체는 넣지 않습니다).
  • 일기 틀은 템플릿 폴더의 노트를 고르면 되고, {{일정}} 자리에 그날 일정이 들어갑니다.

폴더 자동 정리

  • 노트 제목에 폴더 이름이 들어가면(예: 10/18 Brain Dump) 그 폴더로 저절로 옮깁니다.
  • 폴더 이름이 두 개 이상 들어가면 어디로 넣을지 묻습니다. 일기·첨부·템플릿 폴더는 빼고, 이미 맞는 폴더에 있으면 그대로 둡니다.

블록 잡고 오른쪽 클릭

  • Google·네이버·유튜브에서 검색, 노트에서 찾기, 노트 링크로 만들기(없으면 누를 때 새로 만듦), 검색 링크 걸기.
  • Claude에게 묻기: 고른 글을 claude.ai 작은 창에 넣어 엽니다. API 가 아니라 내 claude.ai 구독으로 답하고, 노트 창 옆에 따로 뜹니다. claude.ai 에 로그인돼 있어야 합니다.

베어에서 옮겨 오기

  • 베어에서 파일 → 메모 백업…(또는 설정 → 일반 → 노트 백업)으로 .bear2bk 를 만듭니다.
  • 노트 왼쪽 아래 가져오기에 끌어 놓습니다. 넣을 폴더 이름을 정할 수 있습니다.
  • 태그 · 고정 · 보관 · 만든 날 · 사진이 그대로 오고, 휴지통 노트는 건너뜁니다. 제목의 / 도 그대로입니다.
  • 옵시디언 보관함은 zip 으로 묶어 끌어 놓으면 폴더째 들어옵니다.

Claude 연결

  • claude.ai → 사용자 지정 → 커넥터 → 커스텀 커넥터 추가 → 주소 https://notes.musicits.com/mcp.
  • [연결] → 구글 메일 확인 → 노트 로그인 → 허락.
  • 그 뒤로는 "이번 주 Brain Dump 정리해줘", "오늘 일기에 이거 덧붙여줘" 처럼 말하면 됩니다. Claude 가 고친 것도 기록에 남습니다.
