한 줄 뜻과 내 도구 중 어디에 쓰였는지 적었습니다. 위 검색창에서 바로 찾을 수 있습니다.

B1화면 (웹)브라우저에서 보이는 것

01
HTML
웹 페이지의 뼈대. 제목, 문단, 사진 자리를 적는 글입니다.
쓰인 곳모든 웹 도구, 행사 기록
02
CSS
HTML에 색, 글꼴, 간격을 입히는 규칙입니다.
쓰인 곳포트폴리오, 행사 기록 색 맞추기
03
JavaScript JS
페이지가 눌리고 움직이게 하는 코드. 브라우저 안에서 돌아갑니다.
쓰인 곳손글씨 영상, 코덱 매치
04
React
화면을 조각(부품)으로 나눠 만드는 JavaScript 라이브러리입니다.
쓰인 곳코덱 매치
05
빌드 도구 Vite 등
여러 코드 파일을 브라우저가 빨리 읽는 파일 하나로 묶어 줍니다.
쓰인 곳코덱 매치
06
Canvas
브라우저 안의 그림판. 코드로 이미지를 겹치고 그려서 저장합니다.
쓰인 곳폰 목업, 매거진 커버, 손글씨 영상
07
WebCodecs
브라우저가 직접 영상을 인코딩하는 기능. 서버 없이 MP4를 만듭니다.
쓰인 곳손글씨 영상
08
mp4-muxer
인코딩한 영상 조각과 소리를 MP4 파일 하나로 묶는 라이브러리입니다.
쓰인 곳손글씨 영상
09
localStorage
브라우저가 사이트마다 따로 기억해 두는 작은 저장 공간입니다. 다른 기기와는 공유되지 않습니다.
쓰인 곳오답 노트, 목업 설정 기억
10
공유 시트 Web Share
폰에서 "이미지 저장"·"카톡 보내기" 창을 띄우는 기능입니다.
쓰인 곳폰 목업 (폰에서 저장)
11
PWA
웹 사이트를 앱처럼 홈 화면에 설치해 쓰는 방식입니다.
쓰인 곳뮤직잇츠 노트 "앱 설치"
12
CodeMirror
웹 페이지에 넣는 글 편집기 부품입니다. 단축키, 강조 표시가 됩니다.
쓰인 곳뮤직잇츠 노트 편집 화면
13
Markdown md
# 제목, **굵게**처럼 기호로 서식을 적는 글 형식. markdown-it이 이걸 화면으로 바꿉니다.
쓰인 곳노트, 블로그 초안, 규칙 파일

B2코드·실행맥과 PC에서 돌리는 것

01
Python 파이썬
내 자동화 도구 대부분을 쓴 프로그래밍 언어입니다.
쓰인 곳분석실, 도구모음, 노트 서버, 목업 합성
02
Node.js · npm
JavaScript를 브라우저 밖에서 돌리는 실행기와 그 부품 가게입니다.
쓰인 곳스킬 설치, 노트 편집기 빌드, wrangler
03
터미널
글자로 명령을 쳐서 컴퓨터를 움직이는 창입니다. Claude가 일할 때 주로 여기서 합니다.
쓰인 곳Claude Code가 쓰는 곳
04
.bat · .command
더블클릭하면 정해 둔 명령을 순서대로 실행하는 파일. .bat은 윈도, .command는 맥용입니다.
쓰인 곳분석실, 도구모음 실행 파일
05
라이브러리 · 패키지
남이 만들어 둔 기능 묶음. 가져다 쓰면 처음부터 짤 필요가 없습니다.
쓰인 곳openpyxl, Pillow, Playwright 모두 이것
06
가상환경 venv
도구마다 라이브러리를 따로 넣어 두는 칸막이 폴더입니다. 서로 버전이 꼬이지 않습니다.
쓰인 곳영상용 · TTS용 따로
07
Homebrew
맥에 명령줄 도구를 설치하는 앱스토어 같은 것입니다.
쓰인 곳ffmpeg 등 설치

B3데이터 가져오기남의 서비스에서 받아 오기

01
API
서비스가 프로그램용으로 열어 둔 창구. 정해진 형식으로 물으면 데이터를 줍니다.
쓰인 곳네이버 검색·데이터랩, 검색광고
02
API 키
그 창구를 쓸 수 있다는 내 출입증 번호. 남에게 보이면 안 됩니다.
쓰인 곳네이버, Gemini, Groq, 인스타
03
Graph API
인스타그램·페이스북이 여는 공식 API입니다.
쓰인 곳인스타 분석실
04
RSS
블로그가 새 글 목록을 기계가 읽기 좋게 내놓는 주소입니다. 키가 필요 없습니다.
쓰인 곳경쟁 블로그 비교, IT 뉴스
05
curl
터미널에서 웹 주소의 원본 내용을 그대로 받아 오는 명령어. 화면은 안 그립니다.
쓰인 곳네이버 블로그 후기 찾기 (11/17)
06
Playwright
진짜 브라우저를 코드로 띄워 클릭, 입력, 화면 캡처까지 하는 도구입니다.
쓰인 곳AI 브리핑 인용 추적, 블로그 임시저장 스킬
07
fetch
웹 페이지 안에서 다른 파일이나 데이터를 불러오는 JavaScript 명령입니다.
쓰인 곳사진기능사 문제 불러오기
08
JSON
데이터를 { "이름": 값 } 모양으로 적는 글 형식. 프로그램끼리 주고받을 때 씁니다.
쓰인 곳문제은행, 설정 파일
09
CSV
쉼표로 칸을 나눈 표 파일. 엑셀로 바로 열립니다.
쓰인 곳도구모음 결과, AX 심사표

auto-editor

07
MLX

01

AI가 글을 세는 단위. 한글 한두 글자쯤입니다. 사용량과 요금이 이걸로 정해집니다.

04
스킬

05
메모리
Claude가 다음 대화에서도 기억하도록 남겨 두는 메모 파일입니다.

06
